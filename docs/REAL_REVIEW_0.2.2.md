# 0.2.2 真实服务审阅接入记录

本轮以本地 `main` 上的未提交 0.2.1 为基线，保留 Provider、角色、会话和所有已有修改。生产审阅此前已使用真实 `chat` 请求，不存在失败回退到演示批注的入口；不足在提示词、结果兼容、状态展示及真实验收。

## 本轮改动

- 保留已有 Base URL、官方 SecretStorage 引用、模型发现、手动模型 ID、流式和 Node HTTP/HTTPS 请求。只发送现有最小 `model/messages/stream` 参数，不添加 `response_format`、工具调用或原生 JSON Schema，不切换协议、服务或模型。
- 审阅独立使用 JSON 模式，消除普通讨论中“正常 Markdown / 不输出改稿 JSON”与审阅协议的冲突。
- 严格解析完整 JSON 或一个包裹全部结果的 JSON 围栏，必填字段缺失、空替换、额外字段都拒绝；可选 `replacement` 缺省或 null 只能产生评论。空建议数组是成功结果。
- 本地审阅记录增加文件身份、时间、全文快照、冻结范围和选区、角色规则、Provider ID、模型、requestId、本轮要求及创作偏好。重试固定原文稿和原范围；文稿已变化时要求重新审阅。
- 空正文在请求前拒绝；区分空响应、截断、拒答、格式错误、停止和中断。停止先作废请求身份，再中止真实连接；不保证远端停止计费。
- 服务错误根据实际 code/type/message 分类，区分鉴权、权限、限流、额度、连接、超时、模型不可用；未知 429 不武断归类。详细诊断仅含安全类别、HTTP 状态、插件分类码与阶段。
- 侧栏新增明确的“审阅全文 / 审阅选区”；显示本轮 summary、数量、合法空结果、运行/停止/失败状态；历史附文稿、时间、角色和模型，折叠展示。
- 无法唯一定位时保留评论和原因，禁用采纳、定位和新改法。可靠批注点击定位；预览、忽略、切换候选均不请求模型或写稿。
- 复用原有唯一引用定位、编辑映射、范围保护、单条采纳与安全撤回。新增前向采纳及撤回的 frontmatter 边界保护。
- 关闭侧栏停止在途请求；关闭只读审阅页作废迟到预览，保留其他开放侧栏中的请求。

## 使用与更新

打开 Markdown 并聚焦，保留当前已配置服务和模型，按需要选择创作伙伴，点击“审阅全文”或选择文字后点击“审阅选区”。批注卡片显示模型对当前快照的真实意见。点击卡片定位，点击“预览”查看原文、修订、改后；在只读审阅页点击“采纳”才局部写入。没有替换方案的评论不提供采纳。

安装包 `dist/draft-companion-0.2.2.zip` 和 `dist/draft-companion-0.2.2/draft-companion/` 仅包含 `main.js`、`manifest.json`、`styles.css`。手工更新只替换这三个文件，保留原 `data.json`、密钥管理器数据及回滚目录，再重载插件。未提交、推送或发布到公共仓库。

审阅快照、意见和安全撤回记录保存在已有本地插件数据中，随用户现有同步方案处理。开发诊断只输出阶段、状态、耗时、模型及数量，不输出 API Key、Authorization、整篇私人文稿或原始服务错误。
