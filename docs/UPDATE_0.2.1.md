# 稿伴 0.2.1：选题与标题方法

0.2.1 为“选题编辑”加入参考 BigPengSays/bigpeng-hot-gzh 改编的方法库。沿用原有六角色、聊天、模型配置和批注流程；数据继续使用 schema 2。本次仅本地构建和安装，没有提交、推送或公开发布。

## 使用

打开 Markdown 文稿，在稿伴选择“选题编辑”和“对话”。在“更多操作 → 快捷任务”中新增：

- **按读者问题和现有素材发散选题。** 输入关键词、材料与目标读者，生成最多三个不同方向，每个配两至三个暂定标题，说明已有依据和材料缺口。
- **按不同角度给候选标题，检查正文能否兑现。** 输入明确主题或使用当前草稿，最多给六个不同角度的标题，每条说明面向谁、正文承诺和依据；适用角度不足时不凑数量。

快捷任务只填入输入框，点击“发送”才发起请求。用户明确要求判断是否值得写、收窄选题或比较方向时，优先完成该任务，不强制起标题。选题和标题都是讨论材料，不自动写入正文或确定选题；写正文交由后续角色。

八类选题方法包括可执行清单、亲测复盘、从零教程、新事物落地、对比抉择、开源或替代方案、身份场景化与反常识判断。七类标题角度包括具体清单、真实过程与收获、反转判断、教程路径、可核实的社会证明、同任务对比与克制的口语或情绪钩。

方法以当前材料为依据：没有可靠数字时弃用依赖数字的角度，没有作者经历时不用第一人称亲测，不承诺爆款或点击率，不默认使用夸张词。长度建议可放宽，不冒充平台硬限制。本次没有新增联网搜索，单独给 URL 不代表已读取；外部事实缺来源或日期时指出核实需求。方法及其改编依据见 [来源说明](third-party/bigpeng-hot-gzh.md)。
