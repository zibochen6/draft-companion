# 稿伴 0.3.1：清空对话

侧栏顶部新增常驻“清空对话”按钮，无需在更多菜单中寻找。点击后确认即可清除当前文稿的全部聊天记录，以及对话页、批注页里的未发送输入、追问草稿和任务状态，回到空白对话。

正文、本文要求、角色、模型配置、批注和修改撤回记录保留，其他文稿的聊天与草稿保留。未应用的整篇改稿候选会放弃。如果当前文稿正在生成，清空会停止该请求；迟到回复不会把聊天记录恢复回来。确认时以弹窗显示的文稿为准，切换文稿不会清空另一篇。

清空后需要撤回之前的局部修改，可以在“＋ → 撤回最近局部修改”中操作；整篇候选的旧撤回入口继续保留。清空不会撤销已经写入的文章修改。

本次仍为本地更新，无数据结构升级。安装包只有三个运行文件。现场更新前备份原运行文件和数据，保留原配置、历史及未发送内容；安装动作本身不会自动清空你的实际聊天。通过顶部按钮由用户选择何时清空。

验证记录见 [桌面清空验收](qa-0.3.1/clear-chat-verification.json) 和 [本地安装记录](qa-0.3.1/local-install-verification.json)。核心工具功能沿用 [0.3.0 使用与回退说明](UPDATE_0.3.0.md)。回退至 0.3.0 可以恢复备份运行文件；恢复已清空的聊天须同时恢复清空前的数据备份，文章仍保持其实际内容。
