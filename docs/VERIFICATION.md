## 真实 Obsidian 桌面验证

真实宿主内已完成：

1. 插件加载、原生侧栏打开及复用；本地 Node 网络获取模型列表。
2. 编辑器新增中文与 emoji 后立即发送；在实际 HTTP 请求体中确认最新文字，不依赖模拟回复自述。点击侧栏仍绑定 A。
3. 在实际差异弹窗点击应用选区候选；发送后移动光标不改变范围；范围外字符保持相等；条件撤回恢复原稿。
4. 应用前手工修改阻止旧候选；应用后再手工修改阻止撤回覆盖。
5. A 流式生成时切到 B，B 会话和正文不受影响；切换模型不改变已发出的请求；停止后旧请求不复活。
6. 在真实侧栏派发 composition / 快捷键事件，组词状态不触发发送。这是事件测试，尚未做真人使用 macOS 拼音输入法的手工验收。
7. 官方 SecretComponent 可在真实设置界面打开；模型列表获取、搜索与选择通过，未创建真实密钥。
8. 实际桌面内用模拟服务走完选题、大纲、初稿、应用、审稿、拒绝意见、指定改稿、再次应用、标题摘要。
9. 实际插件重载后恢复会话及拒绝记录；重命名更新关联；删除文件使其候选失效。
10. 检查实际宿主浅色 / 深色样式与差异弹窗。截图发现的侧栏裁剪、多层滚动、跨文稿阅读位置和差异配色问题已修正并复核。截图为合成测试 Vault，见 `gui-light.png`、`gui-dark.png`。

## 真实服务传输验证

使用生产网络模块直接请求 `https://api.meai.cloud/v1/models` 与 `https://api.meai.cloud/v1/chat/completions`。模型列表返回 **37** 个模型；选择列表中实际存在的 `claude-haiku-4-5` 验证聊天，未遍历调用全部模型，也未验证网关背后的实际模型来源。只发送合成测试内容。

| 实测项目 | 结果 |
| --- | --- |
| 模型列表 | 成功，37 个模型，约 2.8 秒。 |
| 非流式中文与 emoji | 完整返回，`stop` 结束，约 6.1 秒。 |
| 流式中文与 emoji | 3 个正文分片，拼接结果一致，`stop` 结束，约 5.4 秒。 |
| 改稿字段 | `explanation`、`replacement`、`notes` 通过实际候选解析，约 22.0 秒。 |
| 主动停止 | 实际收到第一段文本后取消，返回取消状态；观察窗口内无迟到回调。 |
| 强制客户端超时 | 人为设为 1 毫秒后正确中止，无自动重试；这是客户端期限验证，不代表服务异常。 |

机器记录见 [real-api-transport.json](real-api-transport.json)。本轮也修复独立聊天测试：异常结束或空正文不能显示成功，普通讨论也拒绝空响应；共增加 15 项回归验证。

真实 Obsidian 中还验证了初稿和指定改稿候选、实际弹窗应用、冻结选区与范围外字符保护、重复应用拦截、精确撤回、手工编辑后的冲突拦截以及 A/B 停止隔离。**核心操作已验证，但真实请求并非全部正常**：曾出现一次长流式回复缺少完成原因，模型也额外改动了未要求修改的文字。原始失败记录、测试脚本修正及复验边界见 [真实 API 验证](REAL_API_VERIFICATION.md)，汇总机器索引见 [real-api-gui.json](real-api-gui.json)。

## 明确限制与最短人工验收

- 已验证上述真实 HTTPS 服务和模型的基本接口与流式格式。其他服务、全部模型、复杂长文创作质量以及系统 / PAC 代理网络未逐项验证；Node 请求不自动继承系统 / PAC 代理。真实密钥的官方保存与取出全过程未使用本次凭据做持久化验收。
- 未验证 Windows、Linux、移动端或最低版本 1.11.4 的真实安装；移动端明确不支持。
- 离线重命名没有永久稳定文件 ID，身份无法确认时保留旧会话但使候选失效，不扫描全库推断关联。
- 不做自动三方合并、逐条补丁合并、联网核查或公众号发布。停止不保证服务端停止计算或计费。

人工验证：在独立 Vault 安装 ZIP → 添加实际服务根地址和官方密钥引用 → 获取并选择模型 → 独立聊天测试 → 打开合成文稿做讨论 → 选择一段生成改稿 → 预览应用 → 撤回 → 在候选生成后手改正文再尝试应用，确认拦截。另用真实中文输入法组词时按发送快捷键确认不会误发。
