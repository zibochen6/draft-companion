## 换行与其他限制

实机发现 Obsidian 的源文 Editor/View 保存会统一 CRLF 为 LF，切换阅读模式也可能触发保存。稿伴会阻止这条有损源文写入路径。对没有任何源文缓冲、仍保留 CRLF 的文件，原始 `Vault.process` 原子更新已实测保留范围外换行；不能保证宿主先前自行保存的 LF 会自动还原。需要 CRLF 时先保留原始文件，避免源文打开。详见 [更新与回退](UPDATE_0.2.0.md)。

中文 composition 事件与 Enter/Cmd+Enter 行为已验证；物理中文输入法候选窗仍需人工跟进。Windows、Linux、Obsidian 最低版本 1.11.4 未实测。Node 网络路径不自动继承系统/PAC 代理；停止连接不保证服务端停止计费。首版不联网核实事实，不操作公众号后台。
