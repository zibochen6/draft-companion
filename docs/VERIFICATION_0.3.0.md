## 当前已配置的真实模型

使用已配置的 **test_api / mimo-v2.6-flash**，流式开启；密钥只通过官方 SecretStorage 引用取得。临时验证密钥保存在隔离 Vault 的官方密钥存储中，验证后已清除。没有使用用户真实文章，没有访问素材外链，没有逐一测试其他模型。

自动探测确定 **原生工具路径**。两条完整流程通过：

- **选题并勾选**：读取合成选题引用 → 勾选 synthetic-doc-checker → 本地真实文本核验 → 最终自然语言反馈包含实际文件、理由、角度、首推标题和四个备选 → 精确撤回。全文仅偏移 54 的空格变为 `x`，说明和标题没有进入文稿。
- **明确修改选区**：合成正文「这段合成表达需要更直接一些。😀」实际替换为「先核对材料，再写出建议。😀」。frontmatter 和其他段落逐字保留；之后追加独立文字，再撤回这条修改，追加文字保留。

见 [真实模型报告](qa-0.3.0/real-model-verification.json)、[两条完整真实操作证据](qa-0.3.0/real-operation-evidence.json)、[真实选题截图](qa-0.3.0/real-model-topic.png)、[真实局部执行截图](qa-0.3.0/real-model-local-edit.png)。这是接口和写入流程验证，不代表对创作质量、素材事实或所有模型作出保证。

调试时曾遇到超时，以及服务用 `tool_calls:null`、后续工具分片 `id:null / function.name:null` 表示未重复声明的问题。兼容修复只保留先前已收到的完整元数据；最终仍要求完整调用、合法参数和正常完成信号。也修正了意图判断因不传文稿而错误要求再次粘贴材料的问题。上述错误阶段没有执行正文修改；最终通过结果见报告，不使用模拟成功替代真实结果。
