## 已知边界

Obsidian 必须打开；休眠或关闭不能按时运行，补跑不还原历史新闻。网络不自动继承系统/PAC 代理；来源和 Provider 仍可能受速率、权限、容量和超时限制。停止不保证服务端停止计费。源文 CRLF 拒写保护保留；多窗格分叉和未知版本阻止写入/撤回。没有发布、推送或提交。Windows/Linux/移动端和所有模型组合未验证；中文输入法自动化只验证事件保护，真实中文组词需人工验收。
