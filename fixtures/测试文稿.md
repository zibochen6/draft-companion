# 把 AI 写作留在文稿旁边

这份文稿用于验证一个可预览、可应用和可撤回的创作流程。所有内容都是合成测试素材，不代表作者真实使用经历。📝

## 具体场景

写文章时，作者可能在 Markdown 文稿和聊天窗口之间反复复制内容。我们想检验：把讨论放到文稿旁边，能否让修改目标和当前正文更容易对应。

## 必须保留的材料

- 作者判断：工具应保留人的判断，修改需要先预览。
- 测试双链：[[合成资料]]。本轮不读取该笔记。
- 测试嵌入：![[合成案例#片段]]。本轮不展开该嵌入。
- 测试图片：![流程示意](assets/合成示意图.png)。这是待检查的占位引用。
- 测试外链：[示例材料](https://example.com)。仅作为路径测试，不表示已读取网页。

const workflow = ['讨论', '预览', '应用', '撤回'];
